# 몰래 샌드백

키보드를 두드릴 때마다 사실은 샌드백을 한 대씩 치는 스트레스 해소 게임.

## 실행 방법

`index.html`을 브라우저로 바로 열거나, 로컬 서버로 띄우세요:

```bash
npx serve .
# 또는
python3 -m http.server 8080
```

## 조작

- **아무 키 / 클릭** — 샌드백을 한 대씩 패기 (콤보와 "시원함" 게이지 상승)
- 게이지가 가득 차면 샌드백에서 스팀이 터지듯 뿜어져 나오고 화면이 살짝 흔들리는 "완전 해소" 연출이 나옵니다
- 통산 펀치 수 / 최고 콤보는 브라우저 `localStorage`에 저장되어 다음에 열어도 유지됩니다

## 파일 구성

```
real-lab/
├── index.html      마크업
├── css/
│   └── style.css   스타일 (다크 네온 체육관 톤)
├── js/
│   └── script.js   게임 로직 (캔버스 렌더링, 펜듈럼 물리, 이펙트)
└── assets/         정적 리소스 (현재 비어 있음)
```
